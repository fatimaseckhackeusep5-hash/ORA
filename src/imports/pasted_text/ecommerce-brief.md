# CRÉATION DU SITE E-COMMERCE — HERITAGE SHOES

## 1. MISSION

Conçois et développe un **site e-commerce professionnel, moderne, élégant et immersif** pour une marque de chaussures artisanales africaines appelée :

# HERITAGE SHOES

### Slogan :

**« L'élégance africaine à chaque pas. »**

HERITAGE SHOES est une marque qui valorise le savoir-faire artisanal africain à travers des chaussures inspirées des traditions, des matières et de l'identité culturelle africaine, tout en proposant un design contemporain adapté aux goûts actuels.

Le site doit transmettre immédiatement :

**ÉLÉGANCE — HÉRITAGE — ARTISANAT — QUALITÉ — MODERNITÉ**

Le résultat doit ressembler à une **véritable marque de mode premium**, et non à un projet scolaire ou à un template e-commerce générique.

---

# 2. IDENTITÉ VISUELLE

### Couleur principale :

**Marron**

Le marron doit représenter :

* le cuir ;
* la terre ;
* l'artisanat ;
* l'authenticité ;
* la chaleur.

### Couleur secondaire :

**Beige**

Le beige doit apporter :

* élégance ;
* douceur ;
* luminosité ;
* sophistication.

### Couleurs complémentaires

Utiliser ponctuellement :

* ivoire ;
* crème ;
* brun foncé ;
* noir pour certains textes.

Éviter les couleurs trop vives.

La combinaison visuelle générale doit être :

**Marron profond + Beige chaleureux + espaces blancs/crème.**

---

# 3. DIRECTION ARTISTIQUE

Créer une direction artistique inspirée des **maisons de mode contemporaines**, tout en mettant subtilement en valeur l'artisanat africain.

L'esthétique doit être :

**premium · minimaliste · chaleureuse · authentique · contemporaine · élégante**

NE PAS utiliser une esthétique caricaturale de l'Afrique.

Éviter :

* surcharge de motifs ethniques ;
* couleurs excessives ;
* éléments folkloriques partout ;
* design amateur ;
* trop d'ombres ;
* animations excessives.

L'identité africaine doit être présente dans **les matières, les produits, les photographies, les textures et le storytelling**.

---

# 4. TYPOGRAPHIE

Utiliser une combinaison de deux typographies :

### Titres

Une police serif élégante, éditoriale et premium.

### Textes et interface

Une police sans-serif moderne, lisible et minimaliste.

Les titres doivent être grands et respirer.

Exemple de hiérarchie :

**HERITAGE SHOES**

*L'élégance africaine à chaque pas.*

# 23. RESPONSIVE DESIGN

Le site doit être parfaitement responsive :

**Mobile → tablette → desktop**

La version mobile doit être pensée spécifiquement pour le tactile.

Sur mobile :

* menu hamburger ;
* panier facilement accessible ;
* recherche rapide ;
* produits en grille adaptée ;
* boutons suffisamment grands ;
* galerie produit tactile ;
* checkout simplifié.

# 28. ÉLÉMENT DIFFÉRENCIATEUR

Le site doit se différencier des e-commerces classiques grâce au concept :

# « CHAQUE PAIRE A UNE HISTOIRE »

Pour chaque chaussure, lorsque les informations sont disponibles, afficher :

**Qui l'a fabriquée ?**

**Quelle matière a été utilisée ?**

**Quelle technique ?**

**D'où vient l'inspiration ?**

**Combien de temps faut-il pour la fabriquer ?**

Cette dimension doit être au cœur de l'expérience HERITAGE SHOES.

---

# 29. OBJECTIF UX

Le parcours idéal doit être :

**Découvrir → Être séduit → Comprendre l'histoire → Choisir → Acheter → Suivre sa commande**

Le site doit donner envie de continuer à explorer.

L'utilisateur doit ressentir :

> « Cette chaussure est différente. »

puis :

> « Je veux savoir comment elle a été fabriquée. »

puis :

> « Je veux la porter. »

---

# 30. CONSIGNE FINALE

Ne crée PAS un simple template de boutique.

Crée une **véritable expérience de marque**.

HERITAGE SHOES doit se situer à la rencontre de :

**MODE PREMIUM × ARTISANAT AFRICAIN × E-COMMERCE MODERNE**

Le site doit être suffisamment professionnel pour donner l'impression que HERITAGE SHOES est une marque déjà prête à commercialiser ses produits.

L'ensemble doit être :

**élégant, moderne, chaleureux, culturel, premium, intuitif et mémorable.**

Le slogan doit apparaître de manière stratégique dans le site :

# HERITAGE SHOES

### L'élégance africaine à chaque pas.
